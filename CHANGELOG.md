# Changelog

All notable changes to the MITRE ATLAS Agent are documented in this file.

## [1.1.0] - 2026-07-31

### Changed

- Replaced the hierarchical, multi-agent workflow with a single agent that directly uses the vector store, dataset, and graph-visualization tools.
- Reduced agent handoffs and workflow complexity to provide faster responses.
- Updated the bundled ATLAS dataset and vector store to align with MITRE ATLAS data release `v2026.7`.

## [1.0.0] - Initial Public Release

- Initial public release of the MITRE ATLAS Agent.
